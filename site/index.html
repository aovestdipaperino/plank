A coding agent that runs entirely on your Mac. No cloud, no API keys, no “your request has been queued.” Just you, your Metal GPU, and a suspiciously capable piece of wood.

Since you were last here

The plank has been busy.

A few of the newest arrivals. One session can now drive more than one engine, you can pin the pieces of cache worth keeping, and you can walk away from the laptop entirely.

🌲

See inside the cache

/kvcache draws every KV snapshot as the tree it really is — what it was built on, how often you have reused it, when it expires. Pin the expensive ones; the rest age out on their own.

🧩

Several engines, one session

A subagent can name its own model and provider, so a hosted main agent can hand work to the model on your Mac. Each one can get its own git worktree, too.

📱

Leave the desk

/rc starts the remote-control server mid-session, and the bundled web client streams the turn in plank's own theme. It buzzes you when it is your move.
